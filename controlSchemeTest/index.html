Looking for USB joystick…

Power on the Pocket, connect its USB data port, select Joystick, then move a stick. Use desktop Chrome or Edge if it is not detected. Keyboard backup: W/S = left wheel; ↑/↓ = right wheel.

Axes (USB joystick)

Raw axes: no controller connected.

Classic EdgeTX with AETR typically places left vertical on CH3 / Z and right vertical on CH2 / Y. Change these if your radio model differs.

If up moves the wrong way, toggle Invert. The axis selectors show all USB axes exposed by the chosen device; move one stick at a time and watch the readings.
